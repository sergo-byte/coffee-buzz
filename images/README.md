# images/

Сюда локализуются изображения сайта. Ожидаемые файлы:

- `hero.png` — баннер (интерьер кофейни), 16:9
- `latte.png` — латте-арт крупным планом, 1:1
- `breakfast.png` — флэт-лей завтрака, 4:3

Заполнить можно двумя способами:

1. Автоматически — из корня репозитория запусти `bash localize-images.sh`
   (скачает текущие ИИ-плейсхолдеры с CDN и перепишет пути в `index.html`).
2. Вручную — положи сюда реальные фотографии кофейни с этими же именами.
