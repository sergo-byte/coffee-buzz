# Coffee Want — лендинг кофейни ☕

Одностраничный лендинг для московской кофейни **Coffee Want** (ул. Барклая, 10).
Чистый HTML/CSS/JS — без фреймворков, сборки и зависимостей.

**Живое демо:** _добавь ссылку после деплоя_ · **Стек:** HTML5 · CSS3 · vanilla JS

> ⚠️ **Формат проекта:** это концепт-лендинг (spec / портфолио-проект), собранный
> по открытым данным карточки кофейни на Яндекс.Картах. Не является официальным
> сайтом заведения и не был им заказан. Фотографии — ИИ-плейсхолдеры (см. ниже).

---

## Возможности

- **Адаптив** — корректно на десктопе, планшете и мобайле; бургер-меню на узких экранах
- **Анимации** — плавное появление секций на скролле (`IntersectionObserver`), бегущая строка
- **Доступность** — семантичный HTML, видимый фокус клавиатуры, alt-тексты, поддержка `prefers-reduced-motion`
- **Дизайн-система** — тёплая палитра (эспрессо / крем / янтарь + ягодный акцент), шрифты Unbounded + Manrope
- **Реальные данные** — меню, цены, рейтинг и адрес с карточки кофейни; строки меню с «точками-выноской», как в бумажном меню
- **Маршрут в один тап** — кнопки ведут на Яндекс.Карты

## Технологии

`HTML5` · `CSS3` (переменные, Grid/Flex, анимации) · `vanilla JavaScript` · Google Fonts.
Ноль зависимостей и ноль сборки — файл открывается как есть.

## Запуск локально

Открой `index.html` в браузере. Или подними локальный сервер:

```bash
python3 -m http.server 8000
# затем открой http://localhost:8000
```

## Изображения

Три фотографии — ИИ-плейсхолдеры (сгенерированы в Higgsfield) и сейчас отдаются с CDN.
Чтобы сделать сайт полностью самодостаточным, локализуй их одной командой:

```bash
bash localize-images.sh
```

Скрипт скачает картинки в `images/` и перепишет пути в `index.html`.
Для боевой версии замени плейсхолдеры на реальные фотографии кофейни (те же имена файлов).

## Деплой

### GitHub Pages
```bash
git init && git add . && git commit -m "Coffee Want landing"
git branch -M main
git remote add origin https://github.com/<username>/coffee-want.git
git push -u origin main
# затем в настройках репозитория: Settings → Pages → Branch: main / root → Save
```
Сайт появится по адресу `https://<username>.github.io/coffee-want/`.

### Vercel
```bash
npm i -g vercel
vercel        # деплой-превью
vercel --prod # прод-версия
```
